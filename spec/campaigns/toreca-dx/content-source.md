# トレカDX LP content source

## Core positioning

実際のカードショップ運営から生まれた、カードショップ専用モジュール型DXシステム。

## Core message

カドショの、カドショによる、カドショのための、カドショ運営システム。

ヒーローでは、小→中→大→特大の順で以下の4行を表示する。

1. カドショの、
2. カドショによる、
3. カドショのための、
4. カドショ運営システム

ヒーロー説明文：

**買取業務、在庫管理、プライシング業務まで、あなたのカドショに必要な機能を選んで導入するだけ！**
どんなフェーズのカドショでも、**今の業務をラクにできます**

カードショップDXを、必要な分だけ。

システムに店舗を合わせるのではなく、店舗にシステムを合わせる。

## Product model

- トレカDXの業務機能は `MODULE` として表示する。
- POS、EC／通販、その他外部サービスは `INTEGRATION` として表示する。
- 外部サービス自体をトレカDXの提供機能として扱わない。
- 既存システムの置き換えを導入前提にしない。
- 現時点のモジュール表示は例示。正式な提供一覧に基づき最終調整する。

## Desired visitor understanding

- 全部を入れ替えなくてよい。
- 現在のPOSを使いながら導入を検討できる。
- 必要なモジュールから始められる。
- 運営の変化に応じて追加を検討できる。
- 使わない機能を含む大きなパッケージを前提としない。

## Approved section copy

### Audience

カドショの今に合わせて、必要な機能だけ

開業準備中でも、営業中でも、今のシステムを使っていても
店舗の状況に合うところから始められます

1. 開業前｜これから開業する｜何から準備すればいいか分からない｜必要な業務から、小さくスタート
2. 営業中｜今の業務を改善する｜手作業や確認作業に時間がかかっている｜負担の大きい業務だけをラクに
3. システム利用中｜今のシステムに追加する｜POSや通販システムはそのまま使いたい｜必要な機能だけを追加・連携

### Modules

まずはどの業務をラクにしますか？

**目先の業務をラクにして、あとから機能を追加していくこともできちゃいます**
