# トレカDX LP content source

## Core positioning

実際のカードショップ運営から生まれた、カードショップ専用モジュール型DXシステム。

## Core message

カードショップDXを、必要な分だけ。

システムに店舗を合わせるのではなく、店舗にシステムを合わせる。

## Product model

- トレカDXの業務機能は `MODULE` として表示する。
- POS、EC／通販、その他外部サービスは `INTEGRATION` として表示する。
- 外部サービス自体をトレカDXの提供機能として扱わない。
- 既存システムの置き換えを導入前提にしない。
- 現時点のモジュール表示は例示。正式な提供一覧に基づき最終調整する。

## Desired visitor understanding

- 全部を入れ替えなくてよい。
- 現在のPOSを使いながら導入を検討できる。
- 必要なモジュールから始められる。
- 運営の変化に応じて追加を検討できる。
- 使わない機能を含む大きなパッケージを前提としない。

## Prohibited claims

- オールインワン
- すべてをひとつに
- POS機能搭載
- EC機能搭載
- すべてトレカDXだけで完結
- これ一つでカードショップ運営
